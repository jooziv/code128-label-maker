# Code 128 Label Maker

A single-page tool for printing Code 128 barcode labels. Enter one code per line (optionally `code | name`), choose sizes and columns, and download a print-ready PDF or SVG. Includes a phone-friendly Scan view and a clickable card list loaded from `cards.json`.

## Run on GitHub Pages

1. Push `index.html` and `cards.json` to the root of a repository.
2. In the repo, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, and save.
3. The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or so.

Your codes and settings are saved in your browser's local storage.
